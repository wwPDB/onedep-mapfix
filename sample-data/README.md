# Sample Data

This directory contains representative MRC map files used to validate the
MapFix label-prepend POC.

The real deposition examples were downloaded locally during the OneDep MRC
header-label investigation and are tracked with Git LFS because they are large
binary files.

The generated examples under `generated/` are tiny MRC files used for edge-case
testing of multi-line and long labels.

These samples are intended for internal POC validation and handoff only.
